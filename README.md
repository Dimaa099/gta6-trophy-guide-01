An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade exactly as PlayStation publishes them, a guide in our own words with its sources, a six-stage roadmap to the Platinum, the one possibly missable trophy flagged, and a checklist that saves in the browser with export and import, filters by kind and grade, text search, a hide-earned toggle and a spoiler setting that hides un-earned story trophies until they are earned. Static files only — no build step, no network requests at run time.

## Run it

```sh
node serve.ts
```
